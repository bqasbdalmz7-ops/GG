# ناجٍ من الليل — Night Survivor

لعبة Survivors-like / Roguelike كاملة في **ملف HTML واحد مستقل** — بلا إنترنت، بلا مكتبات خارجية، بلا صور أو خطوط خارجية. كل الرسومات بكسل آرت إجرائية مرسومة بالكود ومخزَّنة مؤقتًا، وكل الأصوات مُولَّدة عبر WebAudio. واجهة عربية بالكامل مع دعم RTL، وتعمل على الهاتف (عمودي وأفقي) وعلى سطح المكتب.

## التشغيل

افتح `night-survivor.html` مباشرة في أي متصفح حديث — لا يحتاج خادمًا ولا تثبيتًا.

## التجميع من الأجزاء

نُسِل الملف مقسَّمًا إلى 7 أجزاء مرقّمة (`parts/part01.txt` … `parts/part07.txt`)، كل جزء ≤ 300 سطر حتى يسهل نقله من الهاتف. دمجها بالترتيب يعيد الملف الأصلي بايت-ببايت (تحقّقنا بمطابقة SHA-256):

```bash
cat parts/part01.txt parts/part02.txt parts/part03.txt parts/part04.txt \
    parts/part05.txt parts/part06.txt parts/part07.txt > night-survivor.html
```

## المحتوى

- 9 شخصيات، كل واحدة بسلاح هجومي تلقائي واحد، بإحصائيات مطابقة للمواصفة.
- 3 خرائط (×1.00 / ×1.12 / ×1.25) تؤثر على سرعة الأعداء ومعدل الظهور معًا، ولكل خريطة موسيقى إجرائية خاصة.
- 4 مستويات صعوبة بأرقام مطابقة للمواصفة، وشجرة زعماء إجرائية (زعيم كل دقيقتين، حتى 9) بذَرْ عشوائي 11×13 متماثل.
- تقدّم دائم بالذهب: 5 صفات شخصية + 5 صفات سلاح + 8 مهارات مشتركة + مهارتان خاصتان لكل شخصية. الشراء بالذهب يرفع **الحد الأقصى** فقط، والترقية داخل الجولة تتم عبر 3 بطاقات عشوائية عند كل مستوى.
- حمل عنصر واحد عند الموت إلى الجولة التالية، إحياءان (100 ثم 250 ذهب).
- حفظ `ns1` (v4) مع نسخة احتياطية `ns1_bak` عند الترحيل، و5 خانات جولات (`ns1slot0..4`) مع تعقيم كامل للبيانات التالفة.

## التحقق الآلي (بلا متصفح)

`verify.js` = هيئة محاكاة رأسية (document/canvas/localStorage/AudioContext/… وهمية). `run-tests.js` = 14 مجموعة اختبارات (64 تأكيدًا) تغطي: المستويات الصعبة الأربعة، الشخصيات التاسع، مسار النصر الكامل 1200 ثانية، مسار الموت، شراء الذهب ← بطاقات الترقية ← أثر الإحصائية، حمل العنصر، الإحياءان، حفظ/تحميل، رفض الخانة التالفة، نسخة الترحيل الاحتياطية، وإصلاح sanitize.

```bash
node --check game.js        # game.js = السكربت المستخرج من الملف المجمع (مرفق)
node run-tests.js           # النتيجة: PASS=64 FAIL=0
```

## ما لم يُختبَر آليًا

كل ما يتطلب متصفحًا حقيقيًا: المظهر البصري والالتفاف على الشاشات، اللمس والجويستيك على الهاتف، الصوت الفعلي، الأداء عند الأعداد الكبيرة، وملء الشاشة. التغطية الآلية تنفّذ منطق اللعبة نفسه (نفس السكربت المستخرج من الملف المجمع) لكن دون عرض رسومي.
